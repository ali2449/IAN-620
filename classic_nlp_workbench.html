What is Type-Token Ratio?
Types are unique tokens and tokens are all occurrences. TTR = unique tokens / total tokens. A higher value often indicates more lexical variety, although document length strongly affects it.

  

    Python examples
    

      
Run these examples in Python, Jupyter, or Google Colab.

      

    
Python + collections

    
from collections import Counter
  import re
  
  texts = [
      "NLP processes text and finds patterns.",
      "Text analysis uses words and patterns."
  ]
  
  tokens = [
      token.lower()
      for text in texts
      for token in re.findall(r"\b\w+\b", text)
  ]
  
  frequency = Counter(tokens)
  vocabulary = set(tokens)
  ttr = len(vocabulary) / len(tokens)
  avg_length = sum(len(token) for token in tokens) / len(tokens)
  
  print("Documents:", len(texts))
  print("Tokens:", len(tokens))
  print("Vocabulary:", len(vocabulary))
  print("Type-token ratio:", round(ttr, 3))
  print("Average token length:", round(avg_length, 2))
  print(frequency.most_common(10))

5. Text Normalization and Stop Words

  
Normalization makes different surface forms more consistent. Common steps include lowercasing, handling punctuation, removing stop words, stemming, and lemmatization.

  
Why we use it: “Python” and “python” may represent the same concept. Normalization can reduce unnecessary differences and shrink the feature space.

  
Processed Document 1
Processed Document 2

  
Stop words
Stop words are very common function words such as the, is, and, and of. They are sometimes removed when they contribute little to a task.

  
Important: stop-word removal is not always helpful. Words such as not can be important for sentiment, and modern language models often keep stop words.

6. Stemming and Lemmatization

  
Stemming removes prefixes or suffixes using rules and may create a non-dictionary form. Lemmatization tries to return a valid base or dictionary form called a lemma.

  
Example: studies may stem to studi, while its lemma is study. Lemmatization is usually easier for humans to interpret.

  
The browser demo uses lightweight English rules. Production libraries such as NLTK and spaCy provide more complete algorithms, lexical resources, and grammatical information.

Bag-of-Words creates one column per vocabulary term and stores how many times each word occurs in each document.

  
Strength: simple, fast, and interpretable. Limitation: it mostly ignores word order and meaning. “dog bites man” and “man bites dog” can have the same counts.

10. TF, Document Frequency, IDF, and TF-IDF

  
Term Frequency (TF) measures how much a word occurs in a document. Document Frequency (DF) counts how many documents contain the word. IDF gives less weight to words found in many documents. TF-IDF combines TF and IDF.

  
IDF(t) = ln((N + 1) / (DF(t) + 1)) + 1
TF-IDF(t,d) = Count(t,d) × IDF(t)

  
Intuition: a word receives a higher TF-IDF weight when it is frequent in one document but less common across the corpus.

  

  
Why smooth the IDF formula?
Adding 1 prevents division-by-zero problems and keeps the formula stable for very small corpora like this two-document demo.

  

    Python examples
    

      
Run these examples in Python, Jupyter, or Google Colab.

11. Document Similarity

  
After turning documents into numbers, we can measure how similar they are.

  

    
Cosine Similarity
0.000
Compares the angle between TF-IDF vectors. Values closer to 1 generally mean more similar term patterns.
cos(A,B) = (A · B) / (||A|| ||B||)

    
Jaccard Similarity
0.000
Compares sets of unique tokens: shared vocabulary divided by all unique vocabulary used by either document.
J(A,B) = |A ∩ B| / |A ∪ B|

13. Simple Keyword Extraction with TF-IDF

  
One simple way to identify keywords is to rank terms by their TF-IDF weight. This is not the only keyword-extraction method, but it demonstrates how weighting can highlight distinctive terms.

  
Interpretation: a top keyword is not necessarily the “most important idea.” It is a term that receives a relatively strong numerical weight under this representation.

  
Document 1 Top Terms
Document 2 Top Terms

  

    Python examples
    

      
Run these examples in Python, Jupyter, or Google Colab.

      

    
TF-IDF keyword ranking

    
from sklearn.feature_extraction.text import TfidfVectorizer
  import numpy as np
  
  corpus = [
      "python supports text analysis and machine learning",
      "machine learning models classify text documents"
  ]
  
  vectorizer = TfidfVectorizer(stop_words="english")
  X = vectorizer.fit_transform(corpus)
  terms = vectorizer.get_feature_names_out()
  
  for row_index in range(X.shape[0]):
      scores = X[row_index].toarray().ravel()
      top_indices = np.argsort(scores)[::-1][:5]
      keywords = [(terms[i], round(scores[i], 3)) for i in top_indices if scores[i] > 0]
      print(f"Document {row_index + 1}:", keywords)

  

    

  






  
14. Word Co-occurrence

  
Co-occurrence asks which words appear near one another. Here, two words are counted as co-occurring when they occur within a small token window.

  
Why it matters: co-occurrence is a foundation for association analysis, distributional semantics, word networks, and some classic embedding ideas.

  
  
The table shows up to the 10 most frequent vocabulary terms to keep it readable.

  

  

    Python examples
    

      
Run these examples in Python, Jupyter, or Google Colab.

      

    
Python sliding-window co-occurrence

    
from collections import Counter
  
  text = "nlp models analyze text and text models identify patterns"
  tokens = text.split()
  window_size = 2
  pairs = Counter()
  
  for i, word in enumerate(tokens):
      right = tokens[i + 1:i + 1 + window_size]
      for neighbor in right:
          if word != neighbor:
              pair = tuple(sorted((word, neighbor)))
              pairs[pair] += 1
  
  for pair, count in pairs.most_common(10):
      print(pair, count)

    Greedy vs. lazy matching, groups, boundaries, and escaping
    

      
Greedy quantifiers such as .* consume as much text as possible. Adding ? makes them lazy, so .*? stops at the earliest valid match.

      
Capture groups use parentheses. For example, (\d{2})/(\d{2})/(\d{4}) captures month, day, and year separately. Named groups make those pieces easier to reference.

      
Word boundaries such as \bcat\b match the standalone word cat but not the cat inside category.

      
Escaping matters. A period normally means “any character.” Use \. when you need an actual period. In Python, raw strings such as r"\d+" make regex patterns easier to read.

import re

text = "Call 336-555-0182 or 919-555-0107."
pattern = re.compile(
    r"(?P<area>\d{3})-(?P<prefix>\d{3})-(?P<line>\d{4})"

for match in pattern.finditer(text):
    print("Full match:", match.group(0))
    print("Span:", match.span())
    print("Groups:", match.groupdict())
    print()

# Full match: 336-555-0182

# Groups: {'area': '336', 'prefix': '555', 'line': '0182'}

16. From Text to a Classical Machine-Learning Model

  
Classic NLP often follows a pipeline like the one below. The representation step turns text into numerical features that a machine-learning algorithm can use.

  
Raw documents
     ↓
Sentence splitting / tokenization
     ↓
Optional normalization
     ↓
Vocabulary
     ↓
BoW / N-grams / TF-IDF
     ↓
Numerical feature matrix
     ↓
Naive Bayes / Logistic Regression / SVM / other ML model
     ↓
Prediction

  
Key idea: classic NLP usually requires us to design or choose the text representation explicitly. Modern transformer models learn much richer contextual representations automatically, but these classic methods remain useful, interpretable baselines for many NLP applications.

  

    Python examples

17. Real Project: Movie Review Sentiment Classification

  

    
Goal

    
Build a binary classifier that predicts whether a movie review is positive or negative. The project uses the real movie_reviews corpus distributed through NLTK, which contains 2,000 labeled reviews.

  


  
Expected modeling workflow: define the prediction target, inspect the data, create a clean train/test split, fit text features only on training data, train the model, evaluate it on unseen data, inspect errors, and save the complete pipeline.


  

    
1Define the problemPredict positive vs. negative sentiment from review text.

    
2Load real dataRead the NLTK movie-review corpus into a pandas DataFrame.

    
3Inspect the datasetCheck shape, labels, missing values, duplicates, and text length.

    
4Split the dataCreate stratified training and test sets before fitting the vocabulary.

    
5Represent the textConvert documents to TF-IDF unigram and bigram features.

    
6Train a modelFit Logistic Regression inside a scikit-learn pipeline.

    
7Cross-validateEstimate macro-F1 on the training set before using the test set.

    
8EvaluateReport accuracy, precision, recall, F1, and the confusion matrix.

    
9Inspect errorsReview incorrect predictions to understand model limitations.

    
10Predict new textRun the final pipeline on new, unseen review sentences.

    
11Save the pipelinePersist both TF-IDF and the classifier together with joblib.

    
12Improve carefullyCompare models or parameters using cross-validation, then use the test set for final evaluation.

MetricQuestion it answers

PrecisionWhen the model predicts a class, how often is that prediction correct?

        
RecallHow many reviews from a class did the model successfully find?

        
F1-scoreHow well does the model balance precision and recall?

        
Confusion matrixWhich classes are being confused with one another?

# Real NLP project: movie-review sentiment classification
# Dataset: NLTK movie_reviews (2,000 labeled movie reviews)

import nltk
nltk.download("movie_reviews", quiet=True)

import joblib
import pandas as pd
import matplotlib.pyplot as plt
from nltk.corpus import movie_reviews
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (
    accuracy_score,
    classification_report,
    confusion_matrix,
    ConfusionMatrixDisplay,
)

# 1. Load the real text dataset
rows = []
for label in movie_reviews.categories():
    for file_id in movie_reviews.fileids(label):
        rows.append({
            "text": movie_reviews.raw(file_id),
            "label": label
        })

df = pd.DataFrame(rows)

# 2. Inspect the data
print("Shape:", df.shape)
print(df.head())
print("\nClass counts:")
print(df["label"].value_counts())
print("\nMissing values:")
print(df.isna().sum())
print("Duplicate texts:", df["text"].duplicated().sum())

# Optional text-length feature for exploration
df["text_length"] = df["text"].str.len()
print("\nText length summary:")
print(df["text_length"].describe())

# 3. Basic cleaning
# Do not aggressively remove information before establishing a baseline.
df = df.dropna(subset=["text", "label"]).drop_duplicates(subset="text")

# 4. Split BEFORE fitting TF-IDF to avoid vocabulary leakage
X_train, X_test, y_train, y_test = train_test_split(
    df["text"],
    df["label"],
    test_size=0.20,
    random_state=42,
    stratify=df["label"]
)

print("Train size:", len(X_train))
print("Test size:", len(X_test))

# 5. Build preprocessing + model pipeline
model = Pipeline([
    (
        "tfidf",
        TfidfVectorizer(
            lowercase=True,
            stop_words="english",
            ngram_range=(1, 2),
            min_df=2,
            max_df=0.95,
            max_features=20000,
        )
    ),
    (
        "classifier",
        LogisticRegression(max_iter=1000)
    )
])

# 6. Estimate performance on training data with cross-validation
cv_f1 = cross_val_score(
    model,
    X_train,
    y_train,
    cv=5,
    scoring="f1_macro"
)
print("CV macro-F1 scores:", cv_f1.round(3))
print("Mean CV macro-F1:", round(cv_f1.mean(), 3))

# 7. Train the final model on all training data
model.fit(X_train, y_train)

# 8. Predict the held-out test set
pred = model.predict(X_test)

# 9. Evaluate
print("\nTest accuracy:", round(accuracy_score(y_test, pred), 3))
print("\nClassification report:")
print(classification_report(y_test, pred, zero_division=0))

cm = confusion_matrix(y_test, pred, labels=model.classes_)
print("Confusion matrix:\n", cm)

ConfusionMatrixDisplay(
    confusion_matrix=cm,
    display_labels=model.classes_
).plot()
plt.title("Movie Review Sentiment - Confusion Matrix")
plt.tight_layout()
plt.show()

# 10. Inspect incorrect predictions
results = pd.DataFrame({
    "text": X_test.reset_index(drop=True),
    "actual": y_test.reset_index(drop=True),
    "predicted": pd.Series(pred)
})

errors = results[results["actual"] != results["predicted"]]
print("\nNumber of errors:", len(errors))
print(errors[["actual", "predicted", "text"]].head(5))

# 11. Test the model on new text
examples = [
    "The movie was engaging, funny, and beautifully acted.",
    "The plot was slow and the acting was disappointing."
]
print("\nNew predictions:")
for text, prediction in zip(examples, model.predict(examples)):
    print(prediction, "->", text)

# 12. Save the complete pipeline
joblib.dump(model, "movie_review_sentiment_model.joblib")
print("\nSaved: movie_review_sentiment_model.joblib")

def preprocess_with_spacy(text):
    doc = nlp(str(text))

NMF topics from TF-IDF
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import NMF

vectorizer = TfidfVectorizer(stop_words="english", min_df=3, max_features=5000)
X = vectorizer.fit_transform(df["review"].fillna(""))
