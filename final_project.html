Project Requirements

1

Load and understand the data

Load SQuAD, inspect the columns, and explain how context, question, and answers will be used.

2

Prepare the document collection

Create a collection of unique context passages and retain useful metadata such as title and document ID.

3

Explore the text

Show meaningful EDA such as number of documents, typical passage length, and sample records.

4

Build a TF-IDF baseline

Represent the documents with TF-IDF, use cosine similarity, and retrieve the Top 3 passages for several questions.

5

Create MiniLM-L6 embeddings

Use sentence-transformers/all-MiniLM-L6-v2 for both passage and question embeddings.

6

Store vectors in ChromaDB

Store document IDs, context text, MiniLM-L6 embeddings, and metadata in a ChromaDB collection.

7

Retrieve Top 3 passages

Embed the user question and use ChromaDB to retrieve the three most relevant passages.

8

Compare retrieval methods

Compare TF-IDF with MiniLM-L6 + ChromaDB and discuss at least one case where their behavior differs.

9

Build the RAG prompt

Combine the question with retrieved context and instruct the LLM to answer only from that context.

10

Evaluate the full system

Evaluate retrieval separately from generated answers. Compare no-RAG answers with RAG answers and include at least one failure case.
