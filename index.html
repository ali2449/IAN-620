Course Overview

Extract knowledge from unstructured text

IAN 620 develops an end-to-end NLP workflow in Python, moving from raw text collection to modern language-model applications while emphasizing evaluation, reproducibility, and responsible use.

Course Purpose

This graduate-level course introduces methods for extracting knowledge from unstructured text. Students learn text collection, preprocessing, linguistic analysis, document representation, classification, sentiment analysis, topic modeling, information extraction, word embeddings, deep learning, and transformer models.

The final instructional weeks introduce Generative AI, large language models (LLMs), prompt engineering, embeddings, retrieval-augmented generation (RAG), and responsible use of generative systems.

The course emphasizes practical Python programming and applied analysis of real-world text datasets.

Learning Objectives

What students will be able to do

Explain foundational concepts and applications of text mining and NLP.

Collect, clean, tokenize, normalize, and linguistically annotate text data.

Represent text using Bag-of-Words, TF–IDF, n-grams, and embeddings.

Build and evaluate machine-learning models for text classification and sentiment analysis.

Apply topic modeling, clustering, named entity recognition, and information extraction.

Explain neural sequence models, attention, transformers, and pretrained language models.

Use Generative AI and LLM tools for prompting, semantic search, and basic RAG applications.

Evaluate NLP systems for accuracy, bias, privacy, hallucination, and responsible use.

Technology & Setup

Prepare your NLP workspace

Students need Python 3.x and either a local notebook environment or Google Colab. The course will progressively introduce the libraries required for classical NLP, machine learning, deep learning, transformers, and embeddings.

Easiest Start

Option 1 · Google Colab

Use a browser-based notebook when you want minimal setup. Colab is especially convenient for later deep-learning and transformer demonstrations.

  1. Open Google Colab.
  2. Create a new Python notebook.
  3. Install course packages in notebook cells when needed.
  4. Save a copy of each assignment notebook before submitting through Canvas.
Open Google Colab
Local Workflow

Option 2 · Python / Anaconda + Jupyter

Use a local environment if you prefer full control of packages and files. Anaconda provides Python, Jupyter, NumPy, Pandas, and many common scientific packages.

  1. Install Anaconda or Python 3.x.
  2. Launch Jupyter Notebook or JupyterLab.
  3. Create a dedicated environment for IAN 620 if desired.
  4. Install NLP libraries as they are introduced.

Assignments & Final Project

Reproducible analysis and responsible NLP practice

Programming assignments require executable Python notebooks or scripts with documentation, interpretation, and citations where appropriate. Assignments may address preprocessing, TF–IDF, classification, sentiment, topic modeling, information extraction, embeddings, transformers, and LLM applications. Code that does not execute may receive substantially reduced credit.

The final project requires an end-to-end NLP application using an approved dataset. Deliverables include a short proposal, reproducible code, a written report, and a presentation. Example projects include review analysis, document classification, topic discovery, semantic search, information extraction, summarization, or a basic RAG prototype. Projects must include evaluation, limitations, and responsible-AI considerations.
