Part 5: Clean the Tweet Text

Tweets often contain URLs, user mentions, hashtags, and extra spaces. We will perform simple cleaning before training the model. 

def clean_tweet(text):

    # Remove URLs
    text = re.sub(r"http\S+|www\S+", "", text)

    # Remove user mentions
    text = re.sub(r"@\w+", "", text)

    # Keep hashtag words but remove #
    text = text.replace("#", "")

    # Remove extra spaces
    text = re.sub(r"\s+", " ", text)

    return text.strip()


df["clean_text"] = df["tweet_text"].apply(clean_tweet)

df[["tweet_text", "clean_text"]].head()
Why are we not removing every stop word?
Words such as not, no, and never can be very important for sentiment.

def get_pos_features(text):

    doc = nlp(text)

    return pd.Series({
        "noun_count": sum(token.pos_ == "NOUN" for token in doc),
        "proper_noun_count": sum(token.pos_ == "PROPN" for token in doc),
        "verb_count": sum(token.pos_ == "VERB" for token in doc),
        "adj_count": sum(token.pos_ == "ADJ" for token in doc),
        "adv_count": sum(token.pos_ == "ADV" for token in doc)
    })


pos_features = df["clean_text"].apply(get_pos_features)

Part 7: Named Entity Recognition

Named Entity Recognition identifies names and real-world entities in text.

Entity Meaning Example
PERSON Person A person's name
ORG Organization Pfizer
GPE Country, city, or state India
DATE Date or time period March 2021
PRODUCT Product Product name

Your Task

Create these NER features:

  • person_count
  • org_count
  • gpe_count

  • product_count
  • entity_count

Starter code:

def get_ner_features(text):

    doc = nlp(text)

    return pd.Series({
        "person_count": sum(ent.label_ == "PERSON" for ent in doc.ents),
        "org_count": sum(ent.label_ == "ORG" for ent in doc.ents),
        "gpe_count": sum(ent.label_ == "GPE" for ent in doc.ents),
        "date_count": sum(ent.label_ == "DATE" for ent in doc.ents),
        "product_count": sum(ent.label_ == "PRODUCT" for ent in doc.ents),
        "entity_count": len(doc.ents)
    })


ner_features = df["clean_text"].apply(get_ner_features)

df = pd.concat([df, ner_features], axis=1)

df.head()

Part 8: Create Training and Testing Data

We will keep 80% of the tweets for training and 20% for testing. 

train_df, test_df = train_test_split(
    df,
    test_size=0.20,
    random_state=42,
    stratify=df["label"]
)

print("Training:", train_df.shape)
print("Testing:", test_df.shape)
Why use stratify?
It helps keep approximately the same proportion of negative, neutral, and positive tweets in both the training and testing datasets.

Part 9: Model 1 — TF-IDF

Our first model uses the actual words in the tweets.

Tweet → TF-IDF → Logistic Regression → Sentiment

Create TF-IDF features:

tfidf = TfidfVectorizer(
    max_features=5000,
    ngram_range=(1, 2)
)

X_train_tfidf = tfidf.fit_transform(train_df["clean_text"])
X_test_tfidf = tfidf.transform(test_df["clean_text"])

y_train = train_df["label"]
y_test = test_df["label"]

Train Logistic Regression:

model1 = LogisticRegression(
    max_iter=1000,
    class_weight="balanced"
)

model1.fit(X_train_tfidf, y_train)

pred1 = model1.predict(X_test_tfidf)

Evaluate the model:

print("Accuracy:", accuracy_score(y_test, pred1))

print(
    classification_report(
        y_test,
        pred1,
        target_names=["Negative", "Neutral", "Positive"]
    )
)

Part 11: Model 3 — Combine TF-IDF + POS + NER

Now combine the text features and linguistic features.

TF-IDF + POS + NER → Logistic Regression → Sentiment

Import the required tools:

from scipy.sparse import hstack, csr_matrix
from sklearn.preprocessing import StandardScaler

Scale the numerical linguistic features:

scaler = StandardScaler()

train_ling_scaled = scaler.fit_transform(X_train_ling)
test_ling_scaled = scaler.transform(X_test_ling)

Combine the features:

X_train_combined = hstack([
    X_train_tfidf,
    csr_matrix(train_ling_scaled)
])

X_test_combined = hstack([
    X_test_tfidf,
    csr_matrix(test_ling_scaled)
])

Train Model 3:

model3 = LogisticRegression(
    max_iter=1000,
    class_weight="balanced"
)

model3.fit(X_train_combined, y_train)

pred3 = model3.predict(X_test_combined)

Evaluate:

print("Accuracy:", accuracy_score(y_test, pred3))

print(
    classification_report(
        y_test,
        pred3,
        target_names=["Negative", "Neutral", "Positive"]
    )
)
